# Workspace composition draft — 25 October 2026

Johnny asked for deliberate grouping and hierarchy after the motion repair checkpoint. The selected trial uses an open scene for Journey and a unified working surface for Builder. The accepted packet optics and wallpaper remain the visual foundation.

Journey groups its current endpoint names and retained resolver/address facts in a quiet context band. Request editing moves into the introduction, with its hostname visible while closed. Opening request configuration pauses playback. The original scenario form, validation, presets, source-event seeking and paused sharing remain canonical.

The open scene measures the visible viewport, actual face and envelope geometry, and collapsed playback controls. It balances shorter reading objects within that available region. Playback settings and source details retain their existing independent disclosure contract. Supporting full fields remain available below playback. Other protocol scenes keep their existing composition policy.

Builder groups its existing tabs, device controls, topology, forwarding status and selected-device workbench in one quieter workspace. Canvas tools sit together, the minimap belongs inside the network canvas, and the desktop inspector has a viewport-relative scrolling boundary. Compact widths preserve the existing Network/Workbench pane switch. Initial framing honors a minimum rendered label size around the selected device; the minimap and explicit Frame network action retain the full overview. Editing, probes, configuration history, canonical forwarding and scenario serialization are unchanged.

This is a design trial for visual review, not owner acceptance of the final composition. Source checks and desktop/phone browser review are recorded in the PR. Physical touch devices, Safari, and assistive-technology acceptance remain separate verification boundaries.
