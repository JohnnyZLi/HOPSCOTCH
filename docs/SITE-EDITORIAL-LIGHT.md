# Editorial light visual contract

HOPSCOTCH uses the Journey visual language as the product default: warm paper surfaces, charcoal technical linework, restrained coral for active causal state, and flat translucent construction surfaces. Dark UI is reserved for instruments where contrast is part of the task, such as playback controls, CLI terminals, byte/hex inspectors, and the physical globe.

Workspace-specific theme material must stay with lazy workspace bundles rather than growing the initial CSS bundle. Presentation styling may not alter canonical simulation, captured evidence, measured evidence, provenance, or time semantics.
