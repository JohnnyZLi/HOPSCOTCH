# Home: one request, one routed hop

The home screen places a quiet introduction beside a borderless network scene on desktop. A single IPv4 continuity object arrives from the local network, opens at an edge router, receives the canonical TTL/checksum update, participates in the route decision, and continues toward the next hop. The existing approved packet optics and system typography remain shared with the workspaces. Supporting nodes and controls are deliberately quieter than the packet.

`createHomeJourney()` selects six existing `packet.transit` events from the default request to `example.test`. It uses the existing physical and packet projections; it does not author packet bytes, modify events, or create another simulation. Presentation time is separate from canonical event time. The primary link carries the same portable scenario and current source timestamp into Journey, including when copied or opened in another tab. Builder remains a separate secondary action.

`mountPacketScene()` composes immutable steps through the generated shared painter, glyph reader, value/pacing foundation, and lifecycle motion policy. Geometry comes from available width, actual field layout, and measured text. Packet travel reuses the prepared backing; stationary holds do not rerasterize it. Opening, inspection, field changes, the reader, and route progress preserve one live packet carrier. The animated face is never a resize-observation input.

The introduction plays once per application session and rests at the final source event with the packet's core fields visible. Its transition from the departing carrier to the readable result is continuous; returning home presents that result immediately. The summary is inert until Inspect opens the full anatomy. Pause, Next, and inspection keep control with the visitor. Reduced motion begins with a readable inspected source state and allows stepping through all events directly. Source correctness is immediate; temporary visual copies are inert and leave on settlement or replacement. Page hiding pauses playback. Disposing the scene cancels owned frames, observers, timers, status transitions, and graphics contexts, and removes preview metadata.

Desktop keeps the entire scene in stable bounds with the main actions in the introduction column. Compact layouts put the caption and controls above the route and packet. Full anatomy expands below these anchors; field wrapping determines the required height. Long header descriptions wrap, while addresses remain readable within the supported field widths. The wallpaper extends behind the complete composition in both designed themes.

The home contract compares every selected event, physical projection, packet snapshot and portable handoff against the canonical Journey. Browser checks cover source/byte parity through every step, normal playback order, one-carrier identity, pause/inspection/reversal, focus and inert state, stable primary actions, source-preserving handoff, clean remounting, reduced motion, both themes, and narrow/desktop viewport geometry. Visual review in the isolated browser checks resting and inspected layouts, the actual reader, and the relationship between the scene and its controls before production release.
